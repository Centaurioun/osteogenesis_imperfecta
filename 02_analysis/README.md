# 02_analysis

Purpose: analysis code, notebooks, prompts, and validation workspaces.

## Structure

- `notebooks/active/` — canonical notebook(s) for current replication.
- `notebooks/legacy/` — historical notebook versions retained for comparison.
- `scripts/active/` — active scripts supporting canonical analysis.
- `scripts/legacy/` — superseded scripts/build/patch files.
- `prompts/` — analysis workflow prompts and prompt folders.
- `validation/` — reanalysis and discrepancy-check workspaces.

## Canonical entry

- `notebooks/active/oi_oro_dental_master_FINAL_1_2.ipynb`

## Working practice

- Add new canonical analysis artifacts under `active/` with explicit versioning.
- Keep historical artifacts in `legacy/`; never delete comparison history.
