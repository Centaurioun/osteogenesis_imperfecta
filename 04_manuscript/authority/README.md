# Authority

This folder holds the curated round-two manuscript-facing authority set.

## Contents

- `reports/` for reconciled narrative report copies
- `tables/` for manuscript-facing result tables
- `figures/` for the final figure set when it is ready to surface
- `manuscript_authority_index.md` as the human-readable entry point

## Rule

Only final reconciled round-two assets belong here. Baseline or operational artifacts stay elsewhere and are linked, not relabeled as authority.
