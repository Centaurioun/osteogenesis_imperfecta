# Trace

This folder keeps reproducibility and migration trace items for the manuscript package.

## Contents

- `analysis_code_index.md` for code and source-data pointers
- `migration_map.md` for source-to-destination planning history
- `run_manifests/` for execution manifests
- `robustness_and_supporting_tables/` for supportive round-two output tables

## Rule

Trace files are support material. They help a reviewer reproduce or audit the package, but they are not the manuscript-facing authority itself.
